# 📚 Literary Nexus – Signature Literary Series Landing Page

## Overview

Literary Nexus is a premium, production-ready landing page developed for a fictional cultural institution launching its flagship **Signature Literary Series**.

The project was built as part of a Full-Stack Development Internship assignment with a strong emphasis on:

* Modern Frontend Engineering
* AI-Assisted Development
* Accessibility (WCAG 2.1 AA)
* Lighthouse Optimization
* Responsive Design
* SEO Best Practices
* Production Readiness

---

## 🌐 Live Demo

**Deployment:** https://literary-nexus.vercel.app/

---

## 🎯 Project Objectives

The goal was to create a high-performance static landing page capable of:

* Promoting a premium literary event
* Showcasing featured authors
* Presenting event schedules
* Handling RSVP interactions
* Delivering an exceptional user experience across devices
